# Evidence & Confidentiality

This case study is based on original project artifacts together with factual context from the developer who designed and built the application.

## Evidence reviewed

Reviewed material includes:

- G4 and G6 WINDEV project branches;
- the main calibration-screen image;
- WINDEV project, window and data-definition files;
- the local Microsoft Access database;
- the gear-wheel correction spreadsheet;
- project backup/history artifacts;
- confirmed project context, authorship, correction-algorithm responsibility, and first-hand testing and in-use verification context.

## Public evidence

The repository publishes only selected material needed to explain the project:

- the clean main application screenshot;
- the application workflow and technical notes;
- a sanitized description of the local data model;
- a high-level explanation of correction-to-wheel mapping.

## Material kept private

The repository does not publish:

- the raw Access database;
- the full correction spreadsheet;
- raw WINDEV project or backup files;
- internal filesystem paths;
- operational meter records or serial numbers;
- confidential factory data;
- credentials or internal identifiers.

## Documentation basis

The workflow and technical description in this repository are based on the reviewed project material and first-hand project context. The description of developer-led functional testing and in-use verification is historical first-hand context; no separate formal test plan or execution log is published here.

Proprietary source files and raw operational data remain private.
